# Data Analytics Project: Customer Shopping Behavior Analysis

## Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, SQL, and Power BI. The objective is to transform raw customer shopping data into actionable business insights through data cleaning, exploratory data analysis (EDA), SQL-based querying, and interactive dashboard development.

The project highlights practical data analytics skills commonly used in industry, including data preprocessing, database management, business intelligence reporting, and data visualization.

---

## Dataset

The dataset contains customer shopping behavior information, including:

* Customer demographics
* Purchase history
* Product categories
* Shopping frequency
* Spending patterns
* Transaction details

The data was used to identify customer trends, revenue drivers, and purchasing behavior.

## Project Workflow

### 1. Data Loading

* Imported dataset using Python.
* Performed initial data inspection and validation.
* Checked data types and dataset structure.

### 2. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected inconsistent data entries.
* Standardized column formats.

### 3. Exploratory Data Analysis (EDA)

* Analyzed customer demographics.
* Examined purchasing behavior.
* Identified top-performing product categories.
* Studied spending trends and patterns.
* Created visualizations for business insights.

### 4. SQL Analysis

The cleaned dataset was loaded into PostgreSQL/MySQL/SQL Server for advanced querying.

Sample analyses included:

* Revenue by customer segment
* Product category performance
* Customer purchase trends
* Gender-based spending analysis
* Top customers by revenue
* Monthly sales analysis

### 5. Power BI Dashboard Development

Built an interactive dashboard featuring:

* KPI Cards
* Revenue Analysis
* Customer Segmentation
* Product Category Insights
* Purchase Trend Visualizations
* Interactive Filters and Slicers

## How to Run

### Clone Repository

```bash
git clone https://github.com/your-username/data-analytics-project.git
cd data-analytics-project
```

### Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy
```

### Run Analysis

```bash
jupyter notebook
```

Open the notebook and execute all cells.

### SQL Analysis

1. Create a database in PostgreSQL/MySQL/SQL Server.
2. Import the cleaned dataset.
3. Execute the SQL queries provided in the `sql` folder.

### Power BI Dashboard

1. Open the `.pbix` file in Power BI Desktop.
2. Refresh the data connection.
3. Explore interactive reports and visualizations.
